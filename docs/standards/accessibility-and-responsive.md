# Accessibility and Responsive Standards

**Phụ trách:** Frontend + UX teams  
**Trạng thái:** Frontend-proposed  
**Cập nhật lần cuối:** 2026-07-22

## 1. Keyboard

- Mọi navigation/action dùng được bằng keyboard.
- Focus visible.
- Dialog giữ focus và trả focus về trigger khi đóng.
- Table row action không chỉ dựa vào icon không nhãn.

## 2. Forms

- Label liên kết input.
- Error dùng text, không chỉ màu.
- Date input có format/help rõ.
- Password có autocomplete phù hợp.

## 3. Tables

- Header semantic.
- Mobile có horizontal scroll hoặc card transformation không mất dữ liệu.
- Pagination controls có label.
- Loading/empty/error được announce phù hợp.

## 4. Responsive breakpoints

- Navigation có thể collapse.
- Dashboard cards wrap.
- Form ưu tiên một cột trên màn hình hẹp.
- Confirm dialog không vượt viewport.

## 5. Language

UI wireframe trộn Anh/Việt. Trước release phải chọn locale strategy hoặc chuẩn hóa copy; không để cùng một action có nhiều thuật ngữ không nhất quán.
