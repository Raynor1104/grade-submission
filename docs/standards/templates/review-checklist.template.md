# Review Checklist

## Contract

- [ ] Endpoint/method/payload khớp backend current.
- [ ] Birth Date dùng ISO ở API.
- [ ] Course Name map sang `subject`.
- [ ] Score giữ string.
- [ ] Không gọi endpoint Student/Course update chưa tồn tại.

## UX

- [ ] Loading/empty/error/401.
- [ ] Delete confirmation.
- [ ] Keyboard/focus/labels.
- [ ] Responsive table/form.

## Security

- [ ] Không log password/JWT.
- [ ] 401 clear token.
- [ ] Không raw HTML không an toàn.

## Quality

- [ ] Tests map AC.
- [ ] Lint/typecheck/build pass.
- [ ] Docs/traceability cập nhật.
