# Frontend E2E reference summary

Folder E2E mẫu tổ chức journey theo các nhóm:

- Access control.
- Authentication.
- Domain management journeys.
- Shared system states.
- Performance.

Mỗi scenario gồm:

- Scenario ID.
- Mô tả.
- Acceptance Criteria.
- Điều kiện tiên quyết.
- Các bước.
- Kết quả mong đợi.

Môi trường, seed và reset strategy được tách khỏi journey files để tránh lặp.
